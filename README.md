# Angela Burgos — Portfolio

A high-impact professional portfolio built with Astro and designed for international opportunities in data analytics, applied data science, business intelligence and digital transformation.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:4321`.

## Before publishing

1. Replace `TU-USUARIO` and `/angela-portfolio` in `astro.config.mjs`.
2. Replace the placeholder email, LinkedIn and GitHub links in `src/pages/index.astro`.
3. Add the final portrait in `public/` and replace the placeholder portrait component.
4. Add the final CV to `public/` and connect the download button.
5. Create detailed project pages as the case studies are approved.

## GitHub Pages

Push the repository to GitHub, enable **Settings → Pages → GitHub Actions**, and the included workflow will deploy automatically.
